# 독수리 게임 연결 메모

## 현재

- GPT 로그인이나 API 호출이 필요 없는 정적 React 학습 화면으로 분리.
- ./ 상대 경로를 사용하므로 GitHub Pages의 저장소 하위 경로에서 동작.
- 외부 백엔드·비밀키 없이 실행. 학생 이름과 풀이 기록은 브라우저 localStorage 사용.

## 연결 방식 후보

- 우선 게임 메뉴에서 독립 학습 URL을 열기.
- 필요하면 iframe으로 삽입. 현재 postMessage 송수신은 구현하지 않음.
- 계정·보상 연동을 도입할 때 결과 포맷을 먼저 확정: moduleId, schemaVersion, completed, firstCorrect, totalItems, score, completedAt.
- 게임에서 신뢰하는 점수나 보상으로 사용하려면 서버에서 검증하는 구조가 필요함. 현재 결과는 브라우저 학습 기록과 캡처 인증용.

## 연결 전에 결정할 것

- 독수리 게임 저장소·운영 주소·기술 구성
- 새 창/같은 창/iframe 중 진입 방식
- 학생 식별 방식과 결과 저장 위치
- 첫 시도 채점 규칙과 재시도 규칙을 먼저 확정·구현
