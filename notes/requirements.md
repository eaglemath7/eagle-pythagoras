# 현재 반영 사항

2026-11-11 학교 유인물과 사진 속 답안을 기준으로 갱신했습니다.

- 1번: 공통 밑변 AE → AE ∥ CB → 두 변·끼인각 → SAS → 밑변 AF → AF ∥ CM → 넓이 연결 → 정리 완성
- 2번: 두 직각·공통각 → AA 닮음 → 대응변 비례식 → b² = pc, a² = qc → (p + q)c = c²
- 3번: 대응변 → AB² = 52 → ∠BAE = 90° → 넓이 26
- 빈칸과 보기의 선분에는 실제 윗줄, 평행에는 사선 두 개를 표시합니다.
- 답 클릭 시 즉시 채점하며 정답은 강조 애니메이션 이후 자동 진행합니다. 이유를 별도로 선택하지 않습니다.
- 강조는 두 번만 재생합니다. 선분은 빨간 굵은 선, 삼각형·사각형은 색칠합니다.
- 오답 항목은 한 번만 감점하고 재시도할 수 있습니다. 총 34항목입니다.
- 진행 기록을 복원하며 이전 이유 선택 단계의 감점은 제외합니다.
- 최초 시도 별도 점수와 두 번 오답 시 보기 재구성은 적용하지 않습니다.
