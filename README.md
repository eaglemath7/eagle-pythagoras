# 피타고라스 | 독수리수학

학교 유인물과 제공된 답안을 바탕으로 만든 중2 수행평가 학습 게임입니다.

- 넓이 증명 12단계, 닮음 증명 13단계, 넓이 구하기 9단계
- 보기 선택 즉시 채점, 정답이면 자동으로 다음 빈칸 진행
- 답에 해당하는 선분은 빨간 굵은 선, 도형은 색칠로 두 번 강조
- 선분 윗줄, 사선 평행 기호, 답 길이에 맞춘 빈칸
- 모바일 상단 축소, 짧은 보기 가로 배치
- 34항목 채점, 같은 항목의 오답은 한 번만 감점
- 이름·점수·완료 날짜 인증 화면, 완료 후 모범 답안
- 학원 로고가 들어간 학생용 유인물 PDF

학생용 현재 공개 주소: https://eagle-pythagoras-choice.khkimedu.chatgpt.site/

## 실행

```sh
npm install
npm run build
npm run preview
```

GitHub Pages는 `main` 브랜치의 `/docs`를 게시 폴더로 설정합니다. `docs/`에 빌드 결과와 PDF가 포함됩니다.

기록과 이름은 사용한 브라우저의 localStorage에 저장됩니다. 결과를 서버로 수집하거나 게임 계정과 연결하는 기능은 없습니다.

`src/App.tsx`는 게임과 학습 내용, `src/styles.css`는 화면 스타일입니다. 배포된 Sites 원본과 이 저장소는 별도이므로 후속 수정 시 함께 갱신합니다.
